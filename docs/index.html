Unofficial Python SDK & CLI for Reactive Resume

A production-grade, type-safe Python client and terminal CLI supporting both Synchronous and Asynchronous HTTP operations. Fully aligned with the latest Reactive Resume v6.1.1 API specification.

Get Started Explore CLI API Reference
🔄
Dual Client Engines
Native support for both synchronous (RxResumeClient) and asynchronous (AsyncRxResumeClient) workflows with clean context managers.
🛡️
Full Type Safety
Rigorous Pydantic v2 schemas for all requests, responses, section items, and structured dates with strict runtime validation.
💻
Zero-Dependency CLI
Built-in rxresume CLI tool powered entirely by Python standard library argparse with profile and JSON table outputs.

v6.1.1 Document Trash
Full support for standalone Cover Letters, 30-day trash/restore lifecycle, Custom Domains, and unauthenticated Health checks.

Installation

Install the SDK from PyPI using pip or uv.

The library requires Python 3.11+ and has minimal external dependencies (httpx and pydantic).

Terminal 
# Install standard package
pip install rxresume-python

# Or install with uv (recommended)
uv add rxresume-python

# Include demo & development extras
pip install "rxresume-python[dev,demo]"

Quickstart

Start managing resumes in less than 2 minutes.

import asyncio
from reactive_resume import AsyncRxResumeClient
from reactive_resume.models import Basics, ResumeImportData

async def main():
    async with AsyncRxResumeClient(
        base_url="https://rxresu.me",
        api_key="your_api_key_here"
    ) as client:
        # Check system health
        health = await client.health()
        print(f"Connected to Reactive Resume v{health.version}")

        # List resumes
        resumes = await client.resumes.list(limit=10)
        for r in resumes:
            print(f"- {r.name} (ID: {r.id})")

        # Export resume as PDF bytes
        pdf_bytes = await client.resumes.export(resumes[0].id, format="pdf")
        with open("resume.pdf", "wb") as f:
            f.write(pdf_bytes)

if __name__ == "__main__":
    asyncio.run(main())
from reactive_resume import RxResumeClient

with RxResumeClient(
    base_url="https://rxresu.me",
    api_key="your_api_key_here"
) as client:
    # Check application health
    health = client.health()
    print(f"Service status: {health.status} (v{health.version})")

    # Fetch public resume
    resume = client.resumes.get_public_resume("john_doe", "software-engineer")
    print(f"Profile: {resume.data.basics.name} - {resume.data.basics.headline}")

    # Global overview stats
    stats = client.statistics.get_overview()
    print("Platform statistics:", stats)
# 1. Configure default server & authentication
rxresume config set-url https://rxresu.me
rxresume config set-key your_api_key_here

# 2. Check server health
rxresume health

# 3. List your resumes
rxresume resumes list --format table

# 4. Download resume in PDF format
rxresume resumes download res-123 -o my_cv.pdf --format pdf

System Health API

Unauthenticated service and database health checks.

In Reactive Resume v6.1.1, the GET /api/health endpoint sits at root level outside the OpenAPI namespace and requires no token or API key.

Python 
# Direct shortcut on client
health = client.health()

print("Status:", health.status)      # "ok"
print("Version:", health.version)    # "6.1.1"
print("Database:", health.database.status)
print("Storage:", health.storage.status)

Resumes API (client.resumes)

Full lifecycle management for resume documents.

Method HTTP Route Description
list(limit, offset) GET /resumes List user resumes with optional pagination.
get(id) GET /resumes/{id} Retrieve complete resume entity and JSON schema.
export(id, format) GET /resumes/{id}/exports/{format} Export as pdf, docx, md, or json.
file_import(format, bytes) POST /resumes/file-imports Multipart upload for PDF, JSON Resume, LinkedIn imports.
get_checks(id) GET /resumes/{id}/checks Run deterministic ATS and grammar editor checks.
match_job(id, job_desc) POST /resumes/{id}/job-matches Match resume terms to a job description.
get_preview_url(id) GET /resumes/{id}/web-page/preview Generate 15-minute temporary web preview link.
lock(id, is_locked) POST /resumes/{id}/lock Lock or unlock resume against inadvertent changes.

Cover Letters API (client.cover_letters)

Standalone cover letters introduced in v6 architecture.

Cover letters are independent documents with their own versioning and templates.

Python 
from reactive_resume.models import CoverLetterCreate

# Create a new standalone cover letter
new_letter = client.cover_letters.create(
    CoverLetterCreate(
        name="Google Backend Application",
        slug="google-backend-2026",
        content="Dear Hiring Manager,\n\nI am thrilled to apply..."
    )
)

# Export cover letter as PDF
pdf_data = client.cover_letters.export(new_letter.id, format="pdf")

Documents & Trash API (client.documents)

30-day soft deletion and restoration management.

In Reactive Resume v6, deleting a document moves it to the trash folder for 30 days before permanent deletion.

Python 
# View counts across document types
counts = client.documents.get_counts()
print(f"Resumes: {counts['resumes']}, Trash: {counts['trash']}")

# Move resume to trash
client.documents.trash(type="resume", document_id="res-123")

# Restore document from trash
client.documents.restore("res-123")

# Permanently purge document
client.documents.purge("res-123")

Model Context Protocol (FastMCP Server)

Expose Reactive Resume tools directly to Claude, Cursor, and AI assistants.

The SDK bundles a FastMCP server that turns Reactive Resume into a first-class AI capability suite with 15 tools, 2 prompt templates, and direct document resources.

Terminal 
# Install MCP extras
pip install "rxresume-python[mcp]"

# Run standalone MCP server over stdio
rxresume-mcp

# Or through the rxresume CLI
rxresume mcp --transport stdio

# Run with SSE transport on port 8000
rxresume mcp --transport sse --port 8000

Error Handling

Explicit exception mapping for reliable integrations.

Python 
from reactive_resume import (
    AuthenticationError,
    NotFoundError,
    RateLimitError,
    ServerError,
    RxResumeClient
)

try:
    with RxResumeClient(base_url="https://rxresu.me", api_key="test") as client:
        client.resumes.get("unknown-id")
except AuthenticationError as e:
    print(f"Auth error (401/403): {e.message}")
except NotFoundError as e:
    print(f"Resource not found (404): {e.message}")
except RateLimitError as e:
    print(f"Rate limited (429): {e.message}")
except ServerError as e:
    print(f"Reactive Resume server error (5xx): {e.message}")
