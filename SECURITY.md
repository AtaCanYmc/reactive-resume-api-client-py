# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| 0.5.x   | :white_check_mark: |
| < 0.5.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `rxresume-python`, please report it responsibly.

### How to Report

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   Navigate to the [Security Advisories](https://github.com/AtaCanYmc/reactive-resume-api-client-py/security/advisories) tab and click **"Report a vulnerability"**.

2. **Email**:
   If you are unable to use GitHub Security Advisories, send an email to `atacanymc@gmail.com` with:
   - A detailed description of the issue.
   - Reproduction steps or proof of concept (PoC).
   - Potential impact and affected components.

### What to Expect

- **Acknowledgment**: You will receive an acknowledgment within 48 hours.
- **Assessment**: We will evaluate the report, verify the impact, and keep you informed of progress.
- **Fix & Disclosure**: Once resolved, an update will be published to PyPI and GitHub with credit given to the reporter (unless anonymity is requested).
